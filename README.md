# 90-Day Health Analysis (R)

This project explores 90 days of health-related data using R.

## Questions explored
- Do weekdays and weekends differ in sleep and activity?
- Is sleep duration related to daily step count?
- Are higher step counts associated with lower resting heart rate?

## Data
- `health_data.xlsx`
- Includes realistic missing values for learning purposes

## Tools used
- R
- tidyverse
- ggplot2
- readxl
- lubridate
- janitor
- R Markdown

## How to run
1. Open `Health Project.Rproj` in RStudio
2. Open `health_analysis.Rmd`
3. Click **Knit**

## Output
- HTML report: `output/health_analysis.html`
